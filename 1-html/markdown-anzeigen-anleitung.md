# Markdown-Dateien anzeigen

Markdown-Dateien (`.md`) sind Textdateien mit einer einfachen Auszeichnungssprache.  
Sie können z. B. Überschriften, Listen, Links usw. enthalten.

Es gibt mehrere Möglichkeiten, Markdown „schön“ anzuschauen.

---

## 1. In VS Code anzeigen

1. Öffne die `.md`-Datei in **VS Code**.
2. Drücke:  
   - `Ctrl + Shift + V` → Vorschau in einem neuen Tab  
   - oder im Editor oben rechts auf das Symbol **„Open Preview“** klicken.
3. Mit `Ctrl + K` und dann `V` kannst du die Vorschau auch **neben** der Datei öffnen.

So siehst du links den Markdown-Text, rechts die gerenderte Ansicht.

---

## 2. Auf GitHub (oder ähnlichen Diensten)

Wenn du eine Markdown-Datei auf GitHub hochlädst:

- zeigt GitHub sie automatisch **formatiert** an  
- du kannst zwischen „Code“ (Rohtext) und „Preview“ wechseln.

Das ist praktisch, wenn ihr die Dateien z. B. in einem Kurs-Repository habt.

---

## 3. Lokale HTML-Vorschau mit `markdown-viewer.html`

Wir stellen euch eine kleine HTML-Datei zur Verfügung: `markdown-viewer.html`.

So benutzt du sie:

1. Speichere die Datei `markdown-viewer.html` auf deinem Rechner.
2. Öffne die Datei per **Doppelklick** im Browser (Chrome, Firefox, Edge …).
3. Links im Textfeld:
   - kannst du eigenen Markdown schreiben  
   - oder den Inhalt aus einer `.md`-Datei hineinkopieren.
4. Klicke auf **„Rendern“**.
5. Rechts siehst du die **HTML-Vorschau**.

Hinweis:  
Diese Methode funktioniert komplett **lokal**, es wird nichts ins Internet hochgeladen.

---

## 4. Browser-Erweiterungen (optional)

Für Chrome/Edge/Firefox gibt es Erweiterungen, die `.md` direkt im Browser anzeigen, z. B.:

- „Markdown Viewer“
- „Markdown Preview Enhanced“

Das ist **optional** und vor allem interessant, wenn du häufig mit Markdown arbeitest.
