Übung: Dashboard mit dynamischen Grid-Kacheln

Arbeitsauftrag

Erstelle ein Dashboard aus unterschiedlich großen Kacheln. Nutze dabei die gleiche Technik wie im Galerie-Beispiel: automatische Zeilen, feste Höhe pro Auto-Zeile und Elemente, die mehrere Spalten oder Zeilen überspannen.

  1. Lege für .dashboard ein Grid mit 6 gleich breiten Spalten an.
  2. Gib automatisch erzeugten Zeilen eine Höhe von 70px.
  3. Aktiviere eine dichte Packung mit grid-auto-flow: dense;.
  4. Lasse die Hauptkachel 3 Spalten und 2 Zeilen einnehmen.
  5. Lasse breite Kacheln 2 Spalten einnehmen.
  6. Lasse hohe Kacheln 2 Zeilen einnehmen.

Ziel: ein übersichtliches Kachel-Dashboard.
