# StadtGarten – Aufgabe 02: Bilder, Navigation und Termine

**Kursabschnitt:** Tag 2 (Dienstag)  
**Dateien:** Website im Ordner `stadtgarten/`

> **Projekt:** StadtGarten – die Website eines fiktiven Gemeinschaftsgartens. Arbeite im bestehenden Projektordner `stadtgarten/` weiter. Nutze eigene Texte und geeignete Bilder. Die Website entsteht schrittweise; bereits fertiggestellte Bereiche bleiben erhalten.

## Dein Auftrag
1. Suche mindestens zwei thematisch passende Bilder aus, speichere sie in `images/` und ergänze sie mit sinnvollen Alternativtexten auf der Startseite. Achte auf Dateigröße und Nutzungsrechte.
2. Lege `angebote.html` und `termine.html` an. Verwende eine gemeinsame Navigation mit Links auf die drei Seiten. Alle Links müssen funktionieren.
3. Stelle auf `angebote.html` mindestens vier Angebote vor: Titel, kurzer Beschreibungstext und – wo passend – Bild.
4. Ergänze auf `termine.html` eine Tabelle mit mindestens sechs Terminen. Verwende die Spalten Datum, Uhrzeit, Veranstaltung, Treffpunkt und freie Plätze. Nutze Tabellenüberschrift sowie Kopf- und Datenzellen.
5. Ergänze auf einer Seite einen internen Sprunglink und einen externen Link zu einer sinnvollen Informationsquelle.
6. Ergänze passende Metadaten (insbesondere einen unterschiedlichen Seitentitel und eine Beschreibung) und prüfe die drei HTML-Dateien mit dem HTML-Validator.

## Fertig, wenn …
- die Navigation auf allen Seiten funktioniert;
- die Bilder laden und sinnvolle Alternativtexte besitzen;
- die Termintabelle auch ohne CSS verständlich ist;
- keine unbegründeten HTML-Validierungsfehler auftreten.

**Zusatzaufgabe:** Nutze für ein Bild eine responsive Bildvariante und erkläre kurz, weshalb Du sie gewählt hast.
